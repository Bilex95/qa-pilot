# Design handoff and 404 prevention
Capture deterministic named PNGs from approved HTML; validate dimensions, nonzero bytes and decodability. Commit `design/reference/approved.html` and `design/screenshots/*.png` to target repo/branch, confirm GitHub contents and commit SHA. Only then link screenshots in issues using URLs verified to render for the private repository. Do not assume `../blob/main/...` resolves from an issue page. Recheck after merging. If binary upload cannot be performed, deliver verified ZIP, explain pending commit and do not create broken links. Keep HTML, screenshot inventory and issue references in sync.
