# Engineering baseline
Docker Compose v2 (no top-level `version:`), dev/prod Dockerfiles, healthchecks, non-root production, env.example, reproducible build/test commands, CI lint/type/unit/integration/build. Frontend modular `src/modules/<domain>`, shared design tokens and route role shells. Backend modular `app/modules/<domain>/{api,application,domain,infrastructure,schemas,tests}`, SQLAlchemy 2, Alembic, thin routers and domain services. Protect customer/site data in queries and service layer. Root AGENTS.md short; module-specific instructions only when needed; AI skills referenced rather than copied. No real secrets or unapproved deployments.
